# Egyptalica 🤘

*[العربية 🇪🇬 below / بالعربي في الأسفل](#إيجيبتاليكا-)*

An interactive front-end prototype for **Egyptalica**, a community platform concept for Egypt's rock & metal scene — built as an individual project, combining coursework for the **Cloud Computing** course with an early-stage personal business venture the author is developing from scratch, envisioned as the foundation for a future mobile app.

🔗 **Live demo:** https://pluto6169.github.io/egyptalica/
🔗 **Source code:** https://github.com/pluto6169/egyptalica

> **Note:** This is a front-end prototype (UI/UX + client-side interactivity). Features like Discord login, the marketplace, and messaging are designed and demonstrated in the interface but are not yet connected to a live backend/database.

## About the Project

Egyptalica imagines a dedicated digital home for Egypt's rock and metal community — a place to discover concerts, discuss music, learn genres, buy/sell gear, and connect with other fans and musicians. This prototype was built to explore the full product vision end-to-end before scaling it into a production mobile application, and doubles as an applied project for the Cloud Computing course.

## Prototyped Features

- 🔐 **Auth Concepts** — Discord-based sign-in flow and a fully anonymous guest/profile mode (Reddit-style)
- 🎤 **Live Concerts** — browsable concert listings with an "add concert" flow
- 💬 **Community Discussions** — topic threads, polls, and category filters (Heavy Metal, Death Metal, Egyptian Bands, Gigs, Gear, Scene)
- 📖 **Genre Encyclopedia** — browsable guide to metal and rock subgenres
- 🛒 **Marketplace Concept** — categorized listings for instruments, amps, effects, and gear
- ✉️ **Messaging UI** — DMs and group "rooms" interface
- 📍 **Places & Shops** — map/listing concept for instrument shops and venues
- 🎸 **ChordTrainer Pro** — an interactive chord-practice tool using real-time microphone input for pitch detection, with adjustable BPM, accuracy scoring, and a built-in music theory reference (scales, intervals, chord construction, modal chord charts)
- 🌓 **Dark/Light Mode** and a bilingual-ready, mobile-first interface

## Tech Stack

- **HTML5, CSS3, JavaScript**
- **Web Audio API** — real-time microphone input and pitch detection for the chord trainer

## Getting Started

```bash
git clone https://github.com/pluto6169/egyptalica.git
cd egyptalica
```

Open `index.html` in your browser. For the ChordTrainer's live pitch detection, allow microphone access when prompted.

## Project Status & Roadmap

This is an evolving personal project. Current state: interactive front-end prototype demonstrating the full product concept. Planned next steps include backend/database integration for auth, marketplace, and messaging, followed by a native mobile app build based on this design.

# إيجيبتاليكا 🤘

نموذج أولي تفاعلي (Front-End Prototype) لمنصة **إيجيبتاليكا**، فكرة منصة مجتمعية لسينة الروك والميتال المصري — تم بناؤها كمشروع فردي، بيجمع بين تكليف مقرر **الحوسبة السحابية** ومشروع بيزنس شخصي بيبنيه صاحبه من الصفر، كنموذج أساسي لتطبيق موبايل مستقبلي.

🔗 **رابط الموقع:** https://pluto6169.github.io/egyptalica/
🔗 **الكود المصدري:** https://github.com/pluto6169/egyptalica

> **ملاحظة:** ده نموذج أولي للواجهة الأمامية (UI/UX + تفاعل من جهة العميل). ميزات زي تسجيل الدخول بـ Discord، والـ Marketplace، والرسائل مصممة وموضحة في الواجهة لكنها لسه مش متصلة بباك إند/قاعدة بيانات حقيقية.

## عن المشروع

إيجيبتاليكا بتتخيل بيت رقمي مخصص لمجتمع الروك والميتال في مصر — مكان لاكتشاف الحفلات، مناقشة الموسيقى، تعلّم الأنواع الموسيقية، بيع وشراء الجير، والتواصل مع محبين وموسيقيين تانيين. النموذج ده اتبنى عشان يستكشف رؤية المنتج الكاملة قبل تطويرها لتطبيق موبايل حقيقي، وفي نفس الوقت اتعمل كمشروع تطبيقي لمقرر الحوسبة السحابية.

## المميزات في النموذج الأولي

- 🔐 **مفاهيم المصادقة** — تدفق تسجيل دخول عبر Discord، ووضع ضيف/بروفايل مجهول بالكامل (بأسلوب Reddit)
- 🎤 **الحفلات** — قوائم حفلات قابلة للتصفح مع خاصية "إضافة حفلة"
- 💬 **نقاشات المجتمع** — مواضيع، تصويتات، وفلاتر تصنيف (Heavy Metal, Death Metal, باندات مصرية, حفلات, جير, السين)
- 📖 **موسوعة الأنواع الموسيقية** — دليل قابل للتصفح لأنواع الميتال والروك الفرعية
- 🛒 **فكرة الـ Marketplace** — قوائم مصنفة للآلات، الأمبات، الإفيكتات، والجير
- ✉️ **واجهة الرسائل** — DMs وغرف جماعية
- 📍 **الأماكن والمحلات** — فكرة خريطة/قائمة لمحلات الآلات وأماكن الحفلات
- 🎸 **ChordTrainer Pro** — أداة تدريب كوردات تفاعلية بتستخدم إدخال الميكروفون المباشر لتحليل النغمة، مع BPM قابل للتعديل، تقييم دقة، ومرجع نظرية موسيقى مدمج (سلالم، أبعاد، تركيب الكوردات، جداول كوردات المقامات)
- 🌓 **الوضع الداكن/الفاتح** وواجهة جاهزة لثنائية اللغة ومصممة أولًا للموبايل

## التقنيات المستخدمة

- **HTML5, CSS3, JavaScript**
- **Web Audio API** — إدخال الميكروفون المباشر وتحليل النغمة لأداة تدريب الكوردات
